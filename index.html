体格・目的・使える器具から、あなた専用の1週間メニューを作成

プロフィール入力

使える器具・施設 (複数選択可・未選択なら自重のみ)

トレーニング記録 (記録するとメニュー生成に反映されます)

あなたの1週間メニュー

設定

Anthropic API キーを設定すると、Claude AI があなた専用のメニューを生成します。 キーが未設定の場合は内蔵アルゴリズムでメニューを作成します。

⚠ API キーの取り扱いについて
  • キーはこのブラウザの localStorage にのみ保存され、外部には送信されません(Anthropic API への通信を除く)。
  • 共有 PC では保存しないでください。
  • Claude API の利用には Anthropic の従量課金が発生します。
