# 端末間同期のセットアップ手順

PC・スマホなど複数の端末で学習データ(進捗・復習スケジュール・成績・試験日設定)を
共有するための設定手順です。所要時間はおよそ10分です。

設定しなくてもサイトは動きます。その場合、学習データは開いた端末の中だけに保存されます。

---

## 1. Firebase プロジェクトを作る

1. https://console.firebase.google.com/ を開き、Googleアカウントでログイン
2. 「プロジェクトを追加」をクリック
3. プロジェクト名に `manabit` など好きな名前を入力して「続行」
4. Googleアナリティクスは **オフ** で構いません(「このプロジェクトで Google アナリティクスを有効にする」をオフ)
5. 「プロジェクトを作成」→ 完了まで待つ

## 2. ログイン方法(Google)を有効にする

1. 左メニューの「構築」→「Authentication」→「始める」
2. 「Sign-in method」タブ →「Google」を選択
3. 「有効にする」をオンにし、サポートメールに自分のアドレスを選んで「保存」

## 3. データベース(Firestore)を作る

1. 左メニューの「構築」→「Firestore Database」→「データベースの作成」
2. モードは **本番環境モード** を選択(ルールは次の手順で設定します)
3. ロケーションは `asia-northeast1 (Tokyo)` を選んで「有効にする」

## 4. セキュリティルールを設定する

Firestore の「ルール」タブを開き、内容を次の通りに置き換えて「公開」を押します。
これにより、**自分のデータには自分しかアクセスできなく**なります。

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

## 5. ウェブアプリを登録して構成を取得する

1. 左上の歯車アイコン →「プロジェクトの設定」
2. 「マイアプリ」の欄でウェブアプリのアイコン(`</>`)をクリック
3. アプリのニックネーム(例: `manabit-web`)を入力し、
   「このアプリの Firebase Hosting も設定します」は **チェックせず** 「アプリを登録」
4. 表示される `firebaseConfig` の中から次の4つの値をメモします
   - `apiKey`
   - `authDomain`
   - `projectId`
   - `appId`

## 6. GitHub Pages のドメインを許可する

1. 「Authentication」→「Settings」タブ →「承認済みドメイン」
2. 「ドメインを追加」で `nanu1129.github.io` を追加

## 7. 設定値をサイトに反映する

`ap-study/js/firebase-config.js` を開き、手順5でメモした4つの値を貼り付けて
コミット・プッシュします。

```js
window.AP_FIREBASE_CONFIG = {
  apiKey: 'ここに apiKey',
  authDomain: 'ここに authDomain',
  projectId: 'ここに projectId',
  appId: 'ここに appId',
};
```

> これらの値は公開されても問題のない識別子です(秘密鍵ではありません)。
> 実際のアクセス制御は手順4のセキュリティルールで行っています。

---

## 使い方

1. サイトを開き、ヘッダの雲アイコンをクリック
2. 「Googleでログイン」を押してアカウントを選択
3. 同じ操作をもう一方の端末でも行う(**同じGoogleアカウント**でログインしてください)

以後は自動で同期されます。学習するたびに数秒で保存され、他の端末で開いている画面にも
その場で反映されます。オフラインのときは端末内に記録され、通信が回復したときに同期されます。

## よくある質問

**Q. 両方の端末で別々に学習したデータはどうなる?**
A. 合算されます。解答数や学習日は端末ごとに記録して合計するため、
何度同期しても二重に数えられることはありません。ユニットのクリア状況は
どちらかでクリアしていればクリア扱い、ベストスコアは高い方が残ります。

**Q. 設定(目標問題数・試験日・想起モード)は?**
A. 最後に変更したものが全端末に反映されます。

**Q. ログアウトするとデータは消える?**
A. 消えません。その端末に残り、再ログインすれば再び同期されます。

**Q. 費用はかかる?**
A. 個人利用の範囲であれば Firebase の無料枠(Sparkプラン)に十分収まります。
