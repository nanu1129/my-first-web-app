# 端末間同期のセットアップ手順

PC・スマホなど複数の端末で学習データを自動で共有するための設定手順です。
共有されるのは、進捗、復習の予定、成績、用語カード、過去問の得点、Udemyの視聴チェック、試験日などの設定です。

- 必要なもの: Googleアカウント(Gmailのアカウントで可)
- 所要時間: 約10分(最初の1回だけ)
- 費用: 無料(Firebase の無料プラン「Spark」の範囲で十分です。クレジットカードの登録も不要です)

設定しなくてもサイトは動きます。その場合、学習データは開いた端末の中だけに保存されます。
設定する前に記録を移したいときは、ヘッダの雲アイコンを押して表示される「この端末の記録を送る」と「受け取った記録を読み込む」を使ってください。

> Firebase の画面は、ときどき名前や配置が変わります。
> メニューが見つからないときは、画面上部の検索欄に「Authentication」や「Firestore」と入力すると開けます。

---

## 1. Firebase プロジェクトを作る

1. PCで https://console.firebase.google.com/ を開き、Googleアカウントでログインします。
2. 「Firebase プロジェクトを作成」(または「プロジェクトを追加」)を押します。
3. プロジェクト名に `manabit` など好きな名前を入力し、規約に同意して「続行」を押します。
4. 「AI アシスタンス(Gemini)」と「Google アナリティクス」は、どちらも**オフ**で構いません。
5. 「プロジェクトを作成」を押し、完了したら「続行」を押します。

## 2. Googleログインを使えるようにする

1. 左のメニューから「Authentication」を開き、「始める」を押します。
2. 「ログイン方法」(Sign-in method)のタブで「Google」を選びます。
3. 「有効にする」をオンにし、「プロジェクトのサポートメール」で自分のアドレスを選んで「保存」を押します。
4. 同じ Authentication の「設定」タブ →「承認済みドメイン」→「ドメインを追加」で、次のドメインを追加します。

   ```
   nanu1129.github.io
   ```

## 3. データベース(Firestore)を作る

1. 左のメニューから「Firestore Database」を開き、「データベースを作成」を押します。
2. エディションを聞かれたら「Standard」を選びます。
3. ロケーションは `asia-northeast1 (Tokyo)` を選びます。
4. 「本番環境モードで開始」を選んで「作成」を押します。

## 4. 自分のデータだけを読み書きできるようにする(セキュリティルール)

Firestore の「ルール」タブを開き、書かれている内容を**すべて消して**、次の内容を貼り付けて「公開」を押します。
これで、**自分のデータには自分しかアクセスできなく**なります。

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

## 5. ウェブアプリを登録して、設定値をコピーする

1. 左上の「プロジェクトの概要」(家のアイコン)の横にある歯車 →「プロジェクトの設定」を開きます。
2. 下のほうの「マイアプリ」で、ウェブのアイコン(`</>`)を押します。
3. アプリのニックネーム(例: `manabit-web`)を入力します。
   「Firebase Hosting も設定する」には**チェックを入れず**に「アプリを登録」を押します。
4. 次のような `firebaseConfig` が表示されるので、`{` から `}` までをコピーします。

   ```js
   const firebaseConfig = {
     apiKey: "AIza...",
     authDomain: "manabit-xxxxx.firebaseapp.com",
     projectId: "manabit-xxxxx",
     storageBucket: "...",
     messagingSenderId: "...",
     appId: "1:...:web:..."
   };
   ```

## 6. 設定値をサイトに入れる

次のどちらかで反映します。

- **Claude に頼む場合**: コピーした `firebaseConfig` を、そのまま Claude とのチャットに貼り付けてください。サイトに反映して公開します。
- **自分で入れる場合**: `ap-study/js/firebase-config.js` の4つの値(`apiKey`・`authDomain`・`projectId`・`appId`)を書き換えて、コミット・プッシュします。

> これらの値は、公開されても問題のない識別子です(パスワードや秘密鍵ではありません)。
> データを守っているのは、手順4のセキュリティルールです。

## 使い方

1. サイトを開き、ヘッダの雲アイコンを押します。
2. 「Googleでログイン」を押して、アカウントを選びます。
3. もう一方の端末でも同じ操作をします(**同じGoogleアカウント**でログインしてください)。

これ以降は自動で同期されます。学習すると数秒でクラウドに保存され、ほかの端末で開いている画面にもその場で反映されます。
通信できないときは端末の中に記録しておき、通信が戻ったときに送ります。

- スマホは、Safari や Chrome でサイトを開いてログインしてください。LINE などのアプリの中で開いたページでは、Googleログインができません。
- iPhoneで「ホーム画面に追加」したアプリは、Safariとは記録の保存場所が別です。ホーム画面のアプリで使う場合は、そのアプリの中でログインしてください。

## うまくいかないとき

雲アイコンのパネルに表示されるメッセージで、原因が分かります。

| 表示されるメッセージ | 直し方 |
|---|---|
| ドメインがFirebaseで許可されていません | 手順2-4で `nanu1129.github.io` を追加する |
| Googleログインが有効になっていません | 手順2-3で Google を有効にする |
| データベースのルールで拒否されました | 手順4のルールを貼り付けて「公開」する |
| データベース(Firestore)がまだ作られていません | 手順3を行う |
| ポップアップがブロックされました | ブラウザでこのサイトのポップアップを許可する |

## よくある質問

**Q. 両方の端末で別々に学習したデータはどうなる?**
A. 1つにまとまります。解答数や学習日は端末ごとに記録して合計するため、何度同期しても二重には数えません。
ユニットは、どちらかでクリアしていればクリア扱いになり、ベストスコアは高い方が残ります。

**Q. 設定(試験日・目標・Udemyの視聴チェックなど)は?**
A. 項目ごとに、あとから変更した方が全端末に反映されます。Udemyの視聴チェックはセクションごとにまとまり、学習開始日は早い方の日付が残ります。

**Q. ログアウトするとデータは消える?**
A. 消えません。その端末に残り、もう一度ログインすれば同期が再開します。

**Q. 費用はかかる?**
A. 個人で使う範囲なら、Firebase の無料プラン(Spark)に十分収まります。無料プランは料金が発生しない仕組みです。
